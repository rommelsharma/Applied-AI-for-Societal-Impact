# 📦 Project status — moved to a private repository

This repository is the **public v4.3 predecessor** of **DecisionLens**.

Active development has **moved to a private repository (a private fork)** for
**IP reasons**. In the private fork, the approach has evolved to align with the
**latest industry best practices in the fast-evolving world of RAG design
patterns** — including semantic and structure-aware chunking, parent-document and
contextual retrieval, human-in-the-loop knowledge curation, and a refreshed
product experience.

This public version remains available as a **reference snapshot** of the original
design and is **no longer the active line of development**.
